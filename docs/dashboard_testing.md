# Detection Dashboard Testing Report

## 1. Objective

The purpose of this testing was to verify that the integrated Detect page correctly displays SAR images, predicted oil spill masks, and overlays generated by the trained U-Net model.

The testing also focused on checking image alignment, switching between different SAR samples, and identifying any display issues.

## 2. Testing Setup

- Dashboard tested locally using Streamlit.
- Trained U-Net checkpoint (`unet_best.pth`) configured successfully.
- Four different SAR sample images tested.

## 3. Tests Performed and Results

| Test | Expected Result | Observed Result | Status |
|---|---|---|---|
| Model integration | Dashboard loads the trained U-Net model | Real detection completed successfully | Passed |
| SAR image display | Original radar image displays correctly | All four images displayed | Passed |
| Predicted mask display | Predicted mask corresponds to the selected image | Different masks appeared for different SAR samples | Passed |
| Overlay alignment | Overlay aligns with the predicted mask | Orange regions visually matched the white mask regions | Passed |
| Image switching | Selecting another sample updates the displayed results | Radar images, masks, and overlays updated | Passed |
| Broken images | No missing or broken images | None observed | Passed |
| Display errors | No visible rendering errors | None observed during testing | Passed |

## 4. Sample Testing Observations

**Sample 1:** The dashboard displayed a SAR image, a predicted oil spill mask containing several detected regions, and an overlay that visually matched the mask.

**Sample 2:** Switching to another sample produced a different SAR image and predicted mask. The overlay appeared correctly aligned.

**Sample 3:** The model predicted a small oil region near the image boundary. The mask and overlay displayed consistently.

**Sample 4:** The model predicted a larger oil region. The white mask and orange overlay matched in shape and position.

## 5. Issues and Observations

During testing of the four SAR samples, no display issues, broken images, or incorrect overlay alignment were observed.

The dashboard successfully displayed the original SAR images, predicted masks, and overlays. Switching between different samples also worked correctly.

The map locations and slick outlines are currently simulated, while the detection results are generated using the trained U-Net model.

No dashboard issues requiring fixes were identified during testing.

## 6. Conclusion

The integrated Detect page successfully displayed real U-Net detection outputs for four different SAR samples.

Switching between samples updated the radar image, predicted mask, and overlay. The masks and overlays appeared visually aligned, and no broken images or display errors were observed.
