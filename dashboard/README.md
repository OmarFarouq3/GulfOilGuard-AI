# Dashboard and integration (members 8-9)

Build Streamlit views for imagery/mask overlays, geographic drift maps, and vessel assignments/routes using Plotly where useful. Connect shared schemas and handle missing inputs and unfinished components visibly.

From the repository root, after manual dependency setup, run `streamlit run dashboard/app.py`. The starter displays project status only; it does not run pipelines, access providers, or show simulated results. Keep heavy processing behind explicit user actions. Use clearly labelled synthetic fixtures for independent view development.
